# MEPHI Linux Security 2026

Бухгалтерский шифр обучающегося: 373450

Практическая работа по изучению механизмов безопасности Linux.

## Выполненные разделы

1. Управление пользователями и группами
2. Поиск файлов и мониторинг процессов
3. Изучение механизма SUID
4. Изучение Linux Capabilities
5. Изучение механизма sudo
6. Сбор артефактов

## Основные результаты

- Создан пользователь `user1` с UID 1234.
- Создана группа `students`, пользователь `user1` включён в неё.
- Домашний каталог `/home/user1` имеет права `0700`.
- Для `user1` установлен максимальный срок действия пароля 90 дней.
- Исследованы SUID-файлы и привилегированные процессы.
- Создана SUID-копия `cat-suid`.
- Для `chown-cap` назначена capability `cap_chown=ep`.
- Через `sudo` пользователю `user1` разрешён запуск `/usr/bin/date` от имени root.

## Артефакты

Репозиторий содержит историю команд, результаты `stat`, `getcap`, поиска SUID-файлов, мониторинга процессов, системные файлы пользователей и групп, конфигурацию sudo и контрольный скриншот.
